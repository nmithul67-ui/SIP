# Resilient POS (Phases 1 & 2)

India-first Financial Operating System (POS) for food-and-beverage MSMEs (standalone restaurants and bakeries) operating on budget 10.1-inch Android tablets in landscape orientation (1280x800 / 1920x1200).

For instructions on launching, tablet setup, and testing all features, see the [QUICKSTART.md](file:///e:/sip_!!1/QUICKSTART.md).

## Quick Start

```bash
# Instant launch using pre-compiled production bundle (fastest)
npx serve dist -l 3000

# Or start dev server with hot reload
npx expo start --web
```
